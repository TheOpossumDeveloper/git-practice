# Versioning Strategy: Semantic Versioning (SemVer)

This project follows **Semantic Versioning 2.0.0** to communicate the nature of changes in each release.

## Version Format: `MAJOR.MINOR.PATCH`

1.  **MAJOR:** Incremented when I make incompatible API changes or large structural refactors.
2.  **MINOR:** Incremented when I add functionality in a backwards-compatible manner (e.g., a new "evidence" feature).
3.  **PATCH:** Incremented when I make backwards-compatible bug fixes or documentation updates.

## Current Phase
Currently in **initial development (v0.x.x)** where the focus is on establishing the core structure and Git workflow.
